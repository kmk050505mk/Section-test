# Section test — 202동 단면 투시 실험

단면도 한 장에서 시작한 인터랙티브 단면 투시도입니다. 브라우저에서 바로 열립니다(WebGL 2 필요).

**보기:** GitHub Pages 주소의 `index.html`

## 기능
- 앞쪽 절단면을 고정한 1점 투시. 소실점 드래그, 투시 강도, 공간 깊이 조절
- GPU 선 렌더링: 깊이·법선·부재 번호 버퍼에서 절단(검정) · 윤곽 · 모서리 · 재료 패턴 선 추출
- 사람·식물: 이미지 AI 선화를 잘라 절단면과 평행한 카드로 실제 깊이에 배치
- 같은 모델의 장면: 밤(방별 조명), 햇빛(고도별 그림자), 층 분해, 구성(주거 · 공용 · 정원 · 코어)
- 도면 방식의 실명 · 층 · ▼EL 표기

## 범위와 한계
- 비상업적 개인 실험입니다. 설계 · 구조 검토용 모델이 아닙니다.
- 단면은 래스터 도면을 수작업으로 추적했습니다. 깊이 9.12m는 가정값입니다.
- 저층 포디움 실 구성은 참고 도면의 개념도를 이 단면에 옮겨 재구성했고, 상층부 실 용도는 추정입니다.
- 원본 도면 이미지는 포함하지 않았습니다.
- 작업 방식 참고: Planby “Section to Depth” 재현용 프롬프트. Planby의 코드나 이미지는 사용하지 않았습니다.
